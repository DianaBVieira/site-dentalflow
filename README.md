# DentalFlow — nova versão

Esta pasta inicia o planejamento da nova versão do DentalFlow com base no repositório original `DianaBVieira/DentalFlow`, analisado somente para leitura.

## Documentos

- `docs/diagnostico-v1.md` — o que existe hoje, o que deve ser preservado e quais riscos precisam ser corrigidos.
- `docs/proposta-inicial.md` — objetivos, público, MVP, requisitos, estrutura do produto e arquitetura sugerida.

## Situação

Fase de descoberta e definição. Nenhuma versão foi publicada, nenhum dado real foi copiado e o repositório original não foi alterado.

## Próximo passo recomendado

Validar a proposta com ao menos uma pessoa de cada perfil principal — dentista, recepção e gestão — antes de iniciar a implementação.
